# Security

Friday runs on your own computer and keeps your calendar, tasks and mail on it. If you find a way for someone else to
read or change that, or to run code through Friday, please report it privately: use **Report a vulnerability** on
this repository's Security tab (GitHub's private vulnerability reporting), or write to
friday_support@friday-scheduler.com. Please don't open a public issue for it.

You'll get an answer within a week. Fixes go out as a new version through the app's own updates.
