# Design source

`friday-v22.dc.html` is the Claude Design file "Friday v22" (project 206e74aa-98c9-43d3-a968-78f397be8f0e), the
source of truth for the web app's look and screens since M11. The markup is complete; its trailing prototype script
was cut off at 256 KB by the export, and only drove mock data. Theme tokens and block skins are in the part that came
through (`theme()`, `applyTheme()`, `skinFor()`).
